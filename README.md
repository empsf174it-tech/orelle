# Orelle - Luxury Fragrances

A premium e-commerce boutique portal for a fictional luxury fragrance house, featuring scent note pyramid finders, sample discovery sets, custom packaging, and VIP loyalty rewards.

## Demo Information
- **Authentication**: Auth is client-side DEMO ONLY. The session uses `localStorage` to save name and email. **Never enter real passwords**.
- **Data**: All products, prices, ratings, loyalty points, tiers, orders, and stock states are placeholder demo data.
- **Transactions**: The checkout in the cart drawer is a client-side simulation. No real payments are processed.
- **Safety**: Fragrance safety information (e.g., patch test, keep away from flame, allergens) is placeholder text.

## Tech Stack
- Plain HTML, CSS, JavaScript (ES6+)
- Phosphor Icons (via CDN)
- Google Fonts (Cormorant Garamond, Outfit)

## Features
- **Scent Note Pyramid Finder**: Interactive tool to find matching fragrances based on Top, Heart, and Base notes.
- **Discovery Sets**: Custom sample set builder with live pricing.
- **Custom Packaging**: Live SVG/CSS preview of box style, ribbon, engraving, and gift messages.
- **VIP Rewards**: Tier system, points accumulation and redemption, order history.
- **Cart & Checkout**: Slide-in cart drawer with complete mock checkout flow.
- **User Dashboard**: Overview of points, recent orders, saved scents, saved designs, and rewards.
